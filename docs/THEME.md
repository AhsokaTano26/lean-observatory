# 主题与图表改版

2026-11-21，按用户指定的 https://bandori.fans/en 提炼主题设计。

- 浅色采用暖白纸面、墨色字、细线网格；深色采用暖黑与少量粉色强调。
- 使用横向编号导航、醒目的站点标题、方角面板、合并指标栏和更清楚的排版层级。
- 保留任务状态展示、审计、时间线与报告功能；任务操作由宿主机 CLI 管理，所有 Mock 数据继续明确标识。
- 图表按容器像素重新计算，时间轴使用实际采样时间；缺失数据与长时间中断断开绘制。
- CPU 与内存维持 0–100% 轴；磁盘显示 GiB；下载与上传使用实线和虚线区分。
- 前后端保留 1,801 个采样点，覆盖一秒采样的完整 30 分钟。新打开的任务只显示已有历史。
- 连接丢失或后端采样过期时显示过期状态，不延伸或补造最新资源值。
- 支持指针、触摸和方向键读数，深浅主题持久化，默认浅色。

字体采用设备原生字体栈，没有复制参考站品牌素材，也不依赖外部字体服务。

测试与截图证据见 reports/UI_QA.md。
