# 购机前交付计划

目标：由助手完成全部本地准备；用户购机并提供 SSH/DNS 条件后，由助手部署、验收、启动验证。页面保持纯展示，不向用户交付必须自行执行的部署步骤。

1. 补齐新 Ubuntu 环境探测：Docker 未安装仍输出完整报告；检查权限、架构、端口和资源。
2. 逐文件审阅原项目实际使用的元编程；仅对已审阅且字节哈希一致的扩展放行，未审阅和额外公理仍阻断。
3. 本地实际执行 Lake 构建、类型/公理审计和 fresh checker 小项目，覆盖正式命令路径。
4. 构建/测试 AMD64 镜像，明确原生与模拟验证边界；为正式服务器减少构建等待。
5. 准备安全初装脚本、HTTPS/续期、宿主机监控、线上验收与任务启动门禁，以及一致性备份工具。
6. 完成本地回归、Compose 演练、源码绑定验收和发布；给出可购机结论。

服务器实际资源、端口、受信任证书、真实原始归档哈希与完整证明编译只能在购机后正式阶段验收，不会提前宣布完成。
